STRING:
========
Strings can be compared using equals method:
if( str1.equals(str2) ){...}

To get the char value at the specified index: char ch = str.charAt(5);
The above statement will return the 6th character from the String str [ index starts from 0 ]

To get the length of a String: int len = str.length();
The above statement will return the no of characters present in the String str. If len is 6, then the character indices are 0 to 5

To check if a String is empty or blank, use the methods isEmpty() or isBlank() respectively.

str1.equals(str2);
returns true, if the content of 2 Strings are equal, false otherwise

CONVERSION:
===========
To convert a String to an integer, use the static method: val = Integer.parseInt(str);
Similar methods also exist for other numerical primitives data types, e.g. val = Folat.parseFloat(str);

To convert a numeric primitive to a String, use static toString method:
str = Integer.toString(val);       str2 = Folat.toString(val2);   etc.

parseInt, parseFloat or parseDouble methods may throw NumberFormatException if the given string cannot be converted.
